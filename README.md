# 4-Bit Array Multiplier Using Full Adders

This project implements an unsigned **4-bit × 4-bit binary multiplier** using AND gates and full adders. The circuit was designed in Logisim and described structurally in Verilog.

The design does not use the Verilog multiplication operator (`*`). Instead, it generates partial products and adds them using interconnected full-adder modules.

## Overview

The multiplier accepts two 4-bit unsigned binary numbers:

- `M[3:0]`: Multiplicand
- `Q[3:0]`: Multiplier

It produces one 8-bit unsigned result:

- `P[7:0]`: Product

The mathematical operation is:

```text
P = M × Q
```

The maximum possible result is:

```text
1111₂ × 1111₂ = 15 × 15 = 225 = 11100001₂
```

## Circuit Architecture

The design contains:

- 16 two-input AND operations
- 12 full adders
- Three rows of full adders
- Two 4-bit inputs
- One 8-bit output

### Partial Products

Each partial product is generated by ANDing one bit of `M` with one bit of `Q`:

```text
xij = M[i] AND Q[j]
```

For example:

```text
x00 = M[0] AND Q[0]
x21 = M[2] AND Q[1]
x33 = M[3] AND Q[3]
```

A total of 16 partial products are generated.

The least-significant product bit is directly assigned as:

```text
P[0] = M[0] AND Q[0]
```

The remaining partial products are added using three rows of full adders.

## Full Adder

The reusable full-adder module has three inputs:

- `A`
- `B`
- `Cin`

It has two outputs:

- `Sum`
- `Cout`

The full-adder equations are:

```text
Sum  = A XOR B XOR Cin
Cout = (A AND B) OR (Cin AND (A XOR B))
```

## Running on EDA Playground

1. Open [EDA Playground](https://www.edaplayground.com/).
2. Paste `multiplier_4x4.v` into the Design section.
3. Paste `multiplier_4x4_tb.v` into the Testbench section.
4. Select Verilog as the language.
5. Select Icarus Verilog as the simulator.
6. Enable **Open EPWave after run** if waveform viewing is required.
7. Click **Run**.

The testbench reports whether each multiplication test passes or fails.

## Example

For:

```text
M = 1110₂ = 14
Q = 1011₂ = 11
```

The circuit calculates:

```text
      1110
    × 1011
    --------
      1110
     1110
    0000
+ 1110
------------
  10011010
```

Therefore:

```text
14 × 11 = 154
```

## Design Features

- Structural Verilog implementation
- No use of the multiplication operator
- Reusable full-adder module
- Partial-product generation using AND operations
- Compatible with EDA Playground and Icarus Verilog
- Logisim implementation of the same circuit
- Automated testbench with pass/fail reporting
- Waveform generation through a VCD file


- `M`

- `P`
